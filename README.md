# Sales Data Analysis

## About
This project analyzes sales data using Python.

## Tools Used
- Python
- Pandas
- Matplotlib
- CSV

## Dataset
The dataset contains:
- Date
- Product
- Region
- Sales
- Units

## Analysis
- Total Sales
- Total Units Sold
- Product-wise Sales
- Region-wise Sales
- Monthly Sales Trend

## Project Goal
To understand sales performance and identify useful business insights from the data.
